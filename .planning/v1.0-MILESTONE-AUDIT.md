## Critical Gaps

### 1. INFRA-03: Docker Volume Persistence Broken

**Severity:** Critical
**Impact:** Data does not persist across container restarts in production

The Docker volume mounts at `/app/db`, but `DB_PATH` in `backend/app/db/connection.py:10` defaults to `./db/finally.db`. Since `WORKDIR` is `/app/backend`, this resolves to `/app/backend/db/finally.db` — a path inside the container layer, not the mounted volume.

The test environment masks this bug by explicitly setting `DB_PATH=/app/db/test.db` in `docker-compose.test.yml`.

**Fix:** Change default in `connection.py` to `DB_PATH = os.environ.get("DB_PATH", "/app/db/finally.db")` or set `DB_PATH` in the start script.

### 2. INFRA-06: .env.example Deleted

**Severity:** Medium
**Impact:** New users have no documented environment variable reference

`.env.example` was created in commit f0913cc (Phase 01-01) but accidentally deleted in commit c4cd486 (Phase 02-02). The Phase 1 verification correctly confirmed its existence at the time, but the file was removed in a subsequent phase.

**Fix:** Restore `.env.example` from git history: `git show f0913cc:.env.example > .env.example`

### 3. TEST-06: Watchlist E2E Test Will Fail

**Severity:** Medium
**Impact:** E2E test suite will not pass

`test/e2e/watchlist.spec.ts:14` asserts `expect(addResponse.status()).toBe(201)` but `POST /api/watchlist` returns HTTP 200 (FastAPI default — no `status_code=201` specified).

**Fix:** Either change the test assertion to 200, or add `status_code=201` to the FastAPI route decorator.
