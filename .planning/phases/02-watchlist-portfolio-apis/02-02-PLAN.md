<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> POST /api/portfolio/trade | Untrusted ticker, side, quantity from client |
| price_cache -> portfolio calculation | Cache prices used for P&L (trusted internal) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Tampering | POST /api/portfolio/trade quantity | mitigate | Quantity validated > 0 in route handler (line 88). Side validated to buy/sell only (line 84-85). Pydantic validates type as float. |
| T-02-05 | Tampering | Trade execution atomicity | mitigate | execute_trade in queries.py performs all DB writes in a single connection context with commit at end. If any step fails, uncommitted changes are rolled back by aiosqlite context manager. Verify this in tests. |
| T-02-06 | Information Disclosure | GET /api/portfolio | accept | Returns all positions and cash for default user. Single-user app, no auth. No sensitive data beyond simulated portfolio. |
| T-02-07 | Denial of Service | Rapid trade submissions | accept | Single-user local app. No rate limiting needed. SQLite WAL mode handles concurrent writes. |
| T-02-08 | Elevation of Privilege | user_id parameter default | accept | All queries default to user_id="default". No way for client to specify a different user_id via the API (not exposed in request models). |
</threat_model>
