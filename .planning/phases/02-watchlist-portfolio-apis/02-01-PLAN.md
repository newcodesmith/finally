## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> POST /api/watchlist | Untrusted ticker string from client |
| client -> DELETE /api/watchlist/{ticker} | Untrusted ticker path parameter |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Injection | POST /api/watchlist ticker field | mitigate | Ticker is uppercased and stripped; SQLite uses parameterized queries in queries.py (no string interpolation). Verify in tests that special chars don't cause SQL injection. |
| T-02-02 | Tampering | DELETE /api/watchlist/{ticker} | accept | Path parameter is uppercased/stripped. No sensitive data exposed. Worst case: user removes a ticker they added. Single-user app, no auth. |
| T-02-03 | Denial of Service | POST /api/watchlist | accept | No rate limiting. Single-user local app. Adding many tickers would increase simulator load but is bounded by practical use. |
</threat_model>
