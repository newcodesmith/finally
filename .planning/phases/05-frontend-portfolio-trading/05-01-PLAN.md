2. Create `frontend/src/stores/usePortfolioStore.ts` using Zustand `create`:

```typescript
interface PortfolioStore {
  cashBalance: number;
  totalValue: number;
  positions: Position[];
  snapshots: PortfolioSnapshot[];
  lastTradeResult: TradeResponse | null;
  isTrading: boolean;

  fetchPortfolio: () => Promise<void>;
  fetchSnapshots: () => Promise<void>;
  executeTrade: (req: TradeRequest) => Promise<TradeResponse>;
}
```

- `fetchPortfolio`: GET `/api/portfolio`, update cashBalance, totalValue, positions. Wrap in try/catch, silently fail (keep last values).
- `fetchSnapshots`: GET `/api/portfolio/history`, store array in snapshots. Wrap in try/catch.
- `executeTrade`: set isTrading=true, POST `/api/portfolio/trade` with JSON body, set lastTradeResult, set isTrading=false. On success, immediately call fetchPortfolio() to refresh positions. On network error, return `{ success: false, error: 'Network error', ... }` shape.
- Initialize with cashBalance=10000, totalValue=10000, positions=[], snapshots=[], lastTradeResult=null, isTrading=false.

3. Replace `frontend/src/hooks/usePortfolio.ts` to use the new store instead of local state:

```typescript
'use client';
import { useEffect } from 'react';
import { usePortfolioStore } from '@/stores/usePortfolioStore';

export function usePortfolio(refreshInterval = 5000) {
  const fetchPortfolio = usePortfolioStore((s) => s.fetchPortfolio);
  const fetchSnapshots = usePortfolioStore((s) => s.fetchSnapshots);
  const cashBalance = usePortfolioStore((s) => s.cashBalance);
  const totalValue = usePortfolioStore((s) => s.totalValue);

  useEffect(() => {
    fetchPortfolio();
    fetchSnapshots();
    const interval = setInterval(() => {
      fetchPortfolio();
      fetchSnapshots();
    }, refreshInterval);
    return () => clearInterval(interval);
  }, [fetchPortfolio, fetchSnapshots, refreshInterval]);

  return { cash_balance: cashBalance, total_value: totalValue };
}
```

This maintains the same return shape `{ cash_balance, total_value }` so page.tsx and Header continue working unchanged.
