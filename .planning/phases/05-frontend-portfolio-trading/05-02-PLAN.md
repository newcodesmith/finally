1. Create `frontend/src/types/chat.ts`:

```typescript
export interface ExecutedTrade {
  ticker: string;
  side: string;
  quantity: number;
  price: number;
}

export interface WatchlistChangeResult {
  ticker: string;
  action: string;
  success: boolean;
}

export interface ChatActions {
  trades: ExecutedTrade[];
  watchlist_changes: WatchlistChangeResult[];
  errors: string[];
}

export interface ChatMessage {
  id: string;
  role: 'user' | 'assistant';
  content: string;
  actions?: ChatActions;
  timestamp: string;
}

export interface ChatApiResponse {
  message: string;
  trades: ExecutedTrade[];
  watchlist_changes: WatchlistChangeResult[];
  errors: string[];
}
```

2. Create `frontend/src/stores/useChatStore.ts`:

```typescript
interface ChatStore {
  messages: ChatMessage[];
  isLoading: boolean;
  isOpen: boolean;
  sendMessage: (text: string) => Promise<void>;
  toggleOpen: () => void;
}
```

- `sendMessage`: 
  - Append a user message to `messages` array with `id: crypto.randomUUID()`, `role: 'user'`, `content: text`, `timestamp: new Date().toISOString()`
  - Set `isLoading: true`
  - POST to `/api/chat` with `{ message: text }` body, Content-Type application/json
  - On success: parse JSON as ChatApiResponse, append assistant message with `actions: { trades: response.trades, watchlist_changes: response.watchlist_changes, errors: response.errors }`
  - On any error (network, non-OK status): append assistant message with content "Sorry, something went wrong. Please try again." and no actions
  - Set `isLoading: false`
  - After successful response with trades, call `usePortfolioStore.getState().fetchPortfolio()` to refresh portfolio data
- `toggleOpen`: flip `isOpen` boolean
- Initialize with `messages: [], isLoading: false, isOpen: false`

3. Create `frontend/src/components/ChatMessage.tsx`:
   - `'use client'` directive
   - Props: `message: ChatMessage` (from types/chat.ts)
   - User messages: right-aligned bubble with `bg-accent-purple/20 text-text-primary rounded-lg px-3 py-2 max-w-[80%] ml-auto text-sm`
   - Assistant messages: left-aligned with `bg-surface-hover text-text-primary rounded-lg px-3 py-2 max-w-[80%] text-sm`
   - If `message.actions` exists and has content, render action confirmations below the message text:
     - For each trade in `actions.trades`: a small card/pill with `text-xs px-2 py-1 rounded bg-surface border border-border mt-1`. Content: green circle emoji or `[BUY]`/`[SELL]` label in semantic-up/down color, then `"{quantity} {ticker} @ {formatPrice(price)}"`
     - For each watchlist change in `actions.watchlist_changes`: similar pill. Content: `"+ Added {ticker}"` (semantic-up color) or `"- Removed {ticker}"` (semantic-down color)
     - For each error in `actions.errors`: pill with `text-semantic-down`, prefixed with "Failed: "
  </action>
