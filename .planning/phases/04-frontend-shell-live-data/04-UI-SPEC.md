# Phase 4 — UI Design Contract

> Visual and interaction contract for the frontend shell, live-updating watchlist, sparklines, and main chart area. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (custom Tailwind components) |
| Icon library | lucide-react |
| Font | Inter (system fallback: -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif) |

**Rationale:** This is a specialized trading terminal with custom visualization components (sparklines, price flash animations, charts). A general component library adds weight without benefit. Tailwind CSS with a custom dark theme is the declared approach (D-09, PLAN.md Section 10).

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, ticker symbol to price spacing |
| sm | 8px | Watchlist row internal padding, compact element spacing |
| md | 12px | Watchlist cell padding, inline grouping |
| lg | 16px | Panel internal padding, section spacing |
| xl | 24px | Panel-to-panel gaps, header padding |
| 2xl | 32px | Major layout gaps |

Exceptions: none

**Note:** The 12px value (md) is used because data-dense trading terminals need a spacing step between 8px and 16px for table cells and compact list items.

## Layout Contract

Desktop-first, single-page layout. No scrolling on the main frame (panels scroll internally if needed).

```
+----------------------------------------------------------+
|  HEADER (fixed, full-width)                              |
|  [FinAlly logo/name]  [Portfolio Value]  [Cash]  [SSE *] |
+------------+---------------------------------------------+
|            |                                             |
| WATCHLIST  |  MAIN CHART AREA                           |
| PANEL      |  (selected ticker's price chart)            |
| (left      |                                             |
|  sidebar)  |                                             |
|            |                                             |
| 280px      |  flex-1 (remaining width)                   |
| fixed      |                                             |
|            |                                             |
+------------+---------------------------------------------+
```

### Panel Dimensions

| Panel | Width | Height | Overflow |
|-------|-------|--------|----------|
| Header | 100% | 48px | hidden |
| Watchlist sidebar | 280px fixed | calc(100vh - 48px) | vertical scroll |
| Main chart area | flex-1 (remaining) | calc(100vh - 48px) | hidden (chart fills) |

### Header Layout

Left-aligned: App name "FinAlly" in primary text, 16px semibold.
Right-aligned cluster (8px gaps between items):
- Portfolio total value: yellow `#ecad0a`, 16px semibold, prefixed with "$"
- Separator: muted vertical line `#30363d`
- Cash balance: secondary text `#8b949e`, 14px regular, label "Cash" + value
- Connection status dot: 8px diameter circle with the appropriate status color

### Watchlist Panel

Each watchlist row is a clickable element with the following structure:

```
+--------------------------------------------+
| AAPL        $192.45   +1.23%   [sparkline] |
| ticker      price     change   mini-chart  |
+--------------------------------------------+
```

| Element | Style |
|---------|-------|
| Ticker symbol | 13px, weight 500, primary text color |
| Current price | 13px, weight 400, primary text color, tabular-nums |
| Session change % | 11px, weight 500, green if positive / red if negative / muted if zero |
| Sparkline | 60px wide x 24px tall, stroke color blue `#209dd7`, no fill, 1px stroke width |
| Row padding | 8px vertical, 12px horizontal |
| Row hover | background `#1c2333` |
| Selected row | background `#1c2333`, left border 2px solid yellow `#ecad0a` |
| Row divider | 1px solid `#30363d` (bottom border) |

### Price Flash Animation

When a new price arrives via SSE:
1. Compare `change_direction` field from SSE event
2. If `"up"`: apply `background-color: rgba(38, 166, 65, 0.15)` to the price cell
3. If `"down"`: apply `background-color: rgba(248, 81, 73, 0.15)` to the price cell
4. If `"unchanged"`: no flash
5. Transition: `background-color 500ms ease-out` back to transparent

Implementation: Toggle a CSS class (e.g., `flash-up` or `flash-down`) on price update, remove it after 500ms. Use `transition: background-color 500ms ease-out` on the base element.

### Main Chart Area

- Fill the remaining space after the watchlist sidebar
- Background: dominant `#0d1117`
- Chart line color: blue `#209dd7`
- Chart grid lines: `#1c2333` (subtle, low contrast)
- Chart crosshair/tooltip: secondary surface `#161b22` with primary text
- Chart area padding: 16px on all sides
- Selected ticker name displayed top-left of chart area: 20px semibold, primary text
- Current price displayed next to ticker name: 20px semibold, yellow `#ecad0a`
- Time axis labels: 11px, muted text `#8b949e`
- Price axis labels: 11px, muted text `#8b949e`, tabular-nums

### Empty/Default States

When no ticker is selected (initial page load before user clicks anything):
- Auto-select the first ticker in the watchlist as default
- Chart should display immediately with accumulated SSE data for that ticker

## Interaction Contract

### SSE Connection

| Behavior | Specification |
|----------|--------------|
| Connect | `new EventSource('/api/stream/prices')` on app mount |
| Reconnect | Built-in EventSource retry (browser default) |
| Status tracking | Track `onopen` (connected), `onerror` (reconnecting/disconnected) |
| Data parsing | Parse each SSE `data` field as JSON; fields: `ticker`, `price`, `previous_price`, `session_open_price`, `timestamp`, `change_direction` |

### Price Update Flow

1. SSE event arrives with new price data
2. Update price cache in state (latest price per ticker)
3. Append price + timestamp to sparkline history array for that ticker
4. Trigger price flash animation on the affected watchlist row
5. If the updated ticker is the currently selected ticker, update main chart
6. Recalculate session change % as `((price - session_open_price) / session_open_price) * 100`

### Sparkline Behavior

| Property | Value |
|----------|-------|
| Data source | In-memory array of prices accumulated from SSE since page load |
| Max data points | 120 (approximately 1 minute at 500ms cadence); oldest points dropped when exceeded |
| Rendering | Canvas or SVG line, no axes, no labels, no tooltip |
| Stroke | 1px solid blue `#209dd7` |
| Dimensions | 60px wide, 24px tall |
| Y-axis range | Auto-scale to min/max of accumulated data points |
| Reset | On page reload (intentional per D-04) |

### Ticker Selection

| Action | Result |
|--------|--------|
| Click watchlist row | Set as selected ticker; highlight row with left border; main chart switches to that ticker |
| Default selection | First ticker in watchlist on initial load |
| Visual feedback | Selected row gets left border 2px yellow + background `#1c2333` |
