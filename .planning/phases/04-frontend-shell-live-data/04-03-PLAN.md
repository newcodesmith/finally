**Create MainChart component** (`frontend/src/components/MainChart.tsx`):

- `'use client'` component
- No props — reads selected ticker and its price history directly from Zustand store

**Dynamic import of Lightweight Charts (per Pitfall 4 — "window is not defined" in SSR):**
- Do NOT import `lightweight-charts` at the top level
- Inside a `useEffect`, dynamically import: `const { createChart } = await import('lightweight-charts');`
- This prevents Next.js static export build failure

**Chart setup (in useEffect with empty deps []):**
1. Create a `containerRef = useRef<HTMLDivElement>(null)` for the chart container
2. Create `chartRef = useRef<IChartApi | null>(null)` and `seriesRef = useRef<ISeriesApi<'Line'> | null>(null)` to hold chart/series instances
3. In useEffect:
   - Dynamically import `createChart` and `ColorType` from `lightweight-charts`
   - Create chart in the container div with options:
     ```typescript
     {
       layout: {
         background: { type: ColorType.Solid, color: '#0d1117' },
         textColor: '#8b949e',
         fontSize: 11,
       },
       grid: {
         vertLines: { color: '#1c2333' },
         horzLines: { color: '#1c2333' },
       },
       crosshair: {
         vertLine: { color: '#30363d' },
         horzLine: { color: '#30363d' },
       },
       rightPriceScale: {
         borderColor: '#30363d',
       },
       timeScale: {
         borderColor: '#30363d',
         timeVisible: true,
         secondsVisible: true,
       },
       width: containerRef.current.clientWidth,
       height: containerRef.current.clientHeight,
     }
     ```
   - Add a line series with `color: '#209dd7'` (accent blue) and `lineWidth: 2`
   - Store chart and series in refs
   - Set up a ResizeObserver on the container to call `chart.applyOptions({ width, height })` on resize
   - Cleanup: remove ResizeObserver, call `chart.remove()`

**Data updates (separate useEffect watching selectedTicker and sparklineHistory):**
- Subscribe to `selectedTicker` and the selected ticker's sparkline history from Zustand:
  ```typescript
  const selectedTicker = usePriceStore((s) => s.selectedTicker);
  const priceData = usePriceStore((s) => s.prices[selectedTicker ?? '']);
  const history = usePriceStore((s) => s.sparklineHistory[selectedTicker ?? ''] ?? []);
  ```
- When `selectedTicker` changes or history updates:
  - Convert history array to Lightweight Charts data format. Since we only have price values (no timestamps from sparkline history), use a time counter. Generate time values as sequential seconds from a base time:
    ```typescript
    const baseTime = Math.floor(Date.now() / 1000) - history.length;
    const chartData = history.map((price, i) => ({
      time: (baseTime + i) as Time,
      value: price,
    }));
    ```
  - Call `seriesRef.current.setData(chartData)` to replace all data (this handles ticker switching)
  - On incremental updates (same ticker, new point), could use `series.update()` for the last point, but `setData` on the full array (max 120 points) is fast enough and simpler
- When `selectedTicker` changes, call `chart.timeScale().fitContent()` to auto-zoom

**Display ticker name and current price above chart:**
- Above the chart container div, render a header row:
  - Left: selected ticker name in 20px semibold, `text-text-primary` (#e6edf3)
  - Right: current price in 20px semibold, `text-accent-yellow` (#ecad0a), formatted with `formatPrice()`
- If no selected ticker or no data, show "Waiting for market data..." in `text-text-muted` (#484f58)

**Container styling:**
- Outer div: `flex-1 flex flex-col h-full bg-surface` (#0d1117)
- Chart header: 16px padding, flex row, justify-between, items-baseline
- Chart container div: `flex-1 relative` (Lightweight Charts will fill this)
- 16px padding on all sides of the chart area (per UI-SPEC)

**Update AppShell:**
- Replace the main area placeholder with `<MainChart />`
